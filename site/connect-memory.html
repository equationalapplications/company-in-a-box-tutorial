Step 3 · Connect the memory

An agent with a memory it can't reach is just talk. This page wires your Curated Thoughts brain into Hermes so the agent can search it like any other tool.

The connection uses MCP (Model Context Protocol) — a standard way for agents to use outside tools. Curated Thoughts ships a small helper program called the sidecar that speaks MCP: the app binary doubles as an MCP server, so your agent sees the vault as native tools — semantic recall, wiki search, and more.

  1. Open ~/.hermes/config.yaml and add an mcp_servers entry that launches the Curated Thoughts MCP server:
    mcp_servers:
      curated-thoughts:
        command: "curated-thoughts-mcp"
        args: ["--mcp"]
    (the shape of this block — a command plus args — is the standard Hermes MCP registration)
  2. Restart Hermes so it discovers the new server's tools.
  3. Verify: ask your agent something only the memory would know — "search my vault for what I said about X". If it comes back with your fact, the wiring works.

Shortcut: the next page installs an integration that does this registration for you — and adds a few things plain MCP can't, like automatically surfacing remembered facts in each conversation. If you'd rather not hand-edit config, skip ahead to step 4 and let the integration wire it.
