Step 5 · Give the company standing rules

What makes an agent-run company dependable isn't intelligence — it's rules that hold between conversations. Your company's rule stack has four layers, each a plain file.

  1. INTENT.md — the why. What the company is trying to do, the rules it must follow, what it deliberately does not do. Written for people; agents check every plan against it. It holds intent only — never status or history.
  2. AGENTS.md — the one-line contract for agents working in a codebase: read the intent file first, and every spec must align with it.
  3. Procedures — the how for recurring work: how a delivery happens, how reviews run, what to do when something breaks. Write one whenever the same task has happened twice.
  4. Skills — packaged know-how your Hermes agent loads when a task matches: tool-specific commands, proven workflows, pitfalls. (Hermes calls them skills; plain markdown files they are.)

You already saw the pattern: this exact stack — a human-readable intent file, a minimal agents contract, procedures, and skills — is how Curated Thoughts and CT Integrations are run, and how this very tutorial repo works. Copy the shape, not just the idea.
