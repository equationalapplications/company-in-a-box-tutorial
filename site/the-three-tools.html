Meet the three tools

One remembers, one connects, one does. That's the whole toolbox — and all of it is free and open source.

Curated Thoughts — memory

A desktop app that keeps your company's knowledge in a durable, local "brain": facts, decisions, and lessons, indexed and searchable. Your agents consult it instead of starting from zero every session.

CT Integrations — wiring

An open-source collection of ready-made connections (one per agent harness) that plugs that memory into your agent — so remembered facts show up in the agent's context automatically.

Hermes Agent — the doer

The agent runtime: it holds the roles from the pattern, uses tools, schedules jobs, delegates work, and follows your written procedures.

All of this is open source. Curated Thoughts and CT Integrations are built by Equational Applications; Hermes Agent is built by Nous Research (Equational Applications runs a fork of it). And it's the same stack the real company uses — not a toy demo.
