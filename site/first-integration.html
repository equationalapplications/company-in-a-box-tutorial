Step 4 · Install the integration

Curated Thoughts Integrations is a collection of ready-made connectors — one per agent harness. This step installs the Hermes one, which upgrades your wiring from step 3 into something smarter.

Each integration ships the same layers, adapted to its harness: registration (so you don't hand-edit config), a doctor that checks the whole setup and explains anything broken, agent skills that teach it how to use the memory correctly, and Intuitive Wisdom — remembered facts that arrive in the agent's context when they're relevant, without the agent having to remember to ask.

  1. Get the Hermes integration: go to the releases page for the Hermes integration and grab the latest hermes-v… release.
  2. Install it and run its doctor script — it checks the sidecar, the brain, the vault, and the registration, and tells you exactly what to fix if anything is off.
  3. Restart Hermes. You'll know it worked when remembered facts start showing up in conversations on their own: at session start you get a short recall of relevant procedures and facts, and on each message the integration matches relevant memory to what you just asked.

Other harnesses welcome: the same repo ships integrations for Claude Code, OpenCode, DeepSeek Harness, OpenClaw, and Docker Agent. Your company's memory can feed every agent you use — see the link directory.
