Build a software company in a box

A free, step-by-step tutorial: how one person runs a whole software company — with AI agents doing the work — using three open-source tools. Equational Applications runs exactly this setup for real. This site teaches you the pattern, using their practice as the worked example.

What it is

A software company in a box is you — the CEO — plus AI agents that hold the company's roles: an executive agent that runs the day-to-day, worker agents that do the work, and reviewer agents that check it. The agents remember everything the company learns, follow written procedures, and deliver work through a review process — like a real company, just with a much smaller payroll.

Why use it

It remembers

Everything your agents learn is kept in a durable, searchable memory that survives restarts — and stays yours, on your own machine.

It follows rules

The company runs on written procedures and standing rules, not on whatever the model feels like today. That is what makes it dependable.

It ships

Work goes through a real delivery process — spec, plan, build, independent review, merge — so quality doesn't depend on luck.
