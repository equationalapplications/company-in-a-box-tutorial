Step 1 · Install Hermes Agent

Hermes Agent is the doer — the runtime your executive and worker agents run on. Three commands and you're talking to it.

On Linux, macOS, or WSL2 (the recommended path for this tutorial):

  1. Install it:
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
    When it finishes, reload your shell (source ~/.bashrc or source ~/.zshrc). On macOS or Windows you can instead download the Hermes Desktop installer from the website.
  2. Run the setup wizard:
    hermes setup
    It walks you through choosing an AI provider. The easiest path is hermes setup --portal — one login sets up a model plus web search and a few other tools in one go.
  3. Say hello. Start a conversation and check it responds: that's your agent, alive. hermes starts a chat.

About "profiles": Hermes lets you run several named agents with different roles and settings. That's how Equational Applications separates Tessera (executive) from worker agents — but it's an optional refinement, not an install step. One agent is a perfectly good company to start.
